# Eli mascot for Claude Code

Eli is a small animated mascot who sits right above the message box in Claude Code (desktop Code tab) and reacts to what Claude is doing: he waves at session start, thinks while Claude works, walks while tools run, jumps when Claude finishes, and looks sad for a moment after an error.

Install:

    claude plugin marketplace add EliAFutbol/eli-mascot
    claude plugin install eli-mascot@eli-mascot

Then start a new session.
